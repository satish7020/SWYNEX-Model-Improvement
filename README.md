# SWYNEX Model Improvement

A reproducible machine-learning improvement project for the SWYNEX internship task. It compares a baseline Logistic Regression model with a hyperparameter-tuned Random Forest classifier using the Breast Cancer Wisconsin (Diagnostic) dataset bundled with scikit-learn.

> **Important:** This is a complete, runnable example project. If your Task 2 used a different dataset or selected model, replace the dataset/model section with your actual project before submitting. Report the metrics generated by your own run—do not invent results or claim an improvement unless the evaluation supports it.

## What this project demonstrates

- Train/test split with stratification and a fixed random seed
- Standardization for the Logistic Regression baseline
- Five-fold stratified cross-validation
- Hyperparameter tuning with `GridSearchCV`
- Leakage-safe pipelines
- Holdout evaluation using accuracy, precision, recall, F1, and ROC-AUC
- Model comparison chart, confusion matrices, ROC curves, and feature importance
- Saving the improved model with `joblib`

## Run in VS Code

### 1. Install prerequisites

Install Python 3.10 or newer and Visual Studio Code. In VS Code, install the official **Python** extension by Microsoft.

### 2. Open the project

Extract the ZIP, then in VS Code choose **File → Open Folder** and select `SWYNEX-Model-Improvement`.

### 3. Create a virtual environment

Open **Terminal → New Terminal**.

**Windows PowerShell:**
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use Command Prompt terminal:
```bat
.venv\Scripts\activate.bat
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install libraries

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Select the interpreter

Press `Ctrl+Shift+P` → **Python: Select Interpreter** → choose the interpreter inside `.venv`.

### 6. Run the model

From the project root, run:

```bash
python src/train.py
```

The parameter search can take a few minutes. Wait until the terminal says it saved the model, metrics, reports, and plots.

### 7. Review the outputs

Open the `outputs` folder. The script creates:

- `model_comparison.csv` — holdout metrics for both models
- `model_comparison.png` — metric comparison chart
- `confusion_matrices.png` — classification errors for both models
- `roc_curves.png` — ROC curves
- `feature_importance.png` — top 15 Random Forest features
- `classification_report.txt` — class-level precision/recall/F1
- `best_parameters.json` — selected hyperparameters
- `improved_model.joblib` — trained model file

### 8. Interpret and document the findings

1. Compare both rows in `model_comparison.csv`.
2. Identify the metric most relevant to the task. For medical screening examples, recall for the malignant class can be important; note that scikit-learn labels malignant as class `0`, so inspect the class report and confusion matrix carefully.
3. State whether the improved model actually outperformed the baseline. If one metric improves while another falls, document that trade-off.
4. Mention the dataset, split, cross-validation, tuned parameters, and limitations.
5. Include the generated chart in your repository or LinkedIn post.

```bash
git init
git add .
git commit -m "Add model improvement and evaluation workflow"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/SWYNEX-Model-Improvement.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Do not commit virtual environments or secrets. Generated outputs are ignored by default; if you want to publish charts and metrics, remove the `outputs/*` ignore line from `.gitignore` or force-add selected outputs.
